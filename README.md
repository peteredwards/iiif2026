# IIIF Conference 2026

Map showing the conference venues and some interesting looking stuff to visit.

Uses Leaflet 2.0.0-alpha.1 and the following plugins:

* [Locate Control](https://domoritz.github.io/leaflet-locatecontrol/)
* [Full Screen Control](https://brunob.github.io/leaflet.fullscreen/)
* [Theme Control](https://kristjanesperanto.github.io/leaflet-theme-control/)

This is an experiment using Leaflet version 2 which [marks a major modernization of the Leaflet codebase](https://leafletjs.com/2025/05/18/leaflet-2.0.0-alpha.html).
